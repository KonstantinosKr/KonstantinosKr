### 🌟 Featured Project

#### [Delta](https://github.com/KonstantinosKr/delta)
> *A multiscale contact mechanics Discrete Element Method (DEM) simulator for rigid bodies.*

* **What it does:** Simulates complex interactions of billions of particles using explicit time-stepping. 
* **Key Innovation:** Relies on **triangulated non-spherical particles** rather than standard spheres, combining robust exact geometry checks with fast penalty-based methods.
* **Performance:** Leverages asynchronous data exchange via MPI across manycore supercomputers, handling ghost particles across overlapping subdomains alongside node-level shared memory and SIMD optimizations.
